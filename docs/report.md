**1. Що змінилося у виводі git status після git add?**

Після git add файли переходять до розділу Changes to be committed. Це означає, що вони додані до індексу та готові до commit.

Команда git diff показує зміни у файлах: додані рядки позначаються знаком +, а видалені — знаком -.

git switch main перемикає на гілку main, а git merge об'єднує зміни іншої гілки з поточною.

## W-10

**1. Що робить flex-wrap та навіщо потрібен медіа-запит?**

flex-wrap: wrap дозволяє flex-елементам переноситися на новий рядок, якщо вони не вміщаються в одному ряду. Без нього елементи стискаються або виходять за межі контейнера. Медіа-запит дає змогу застосувати інші стилі лише за певної ширини екрана. Наприклад, на телефоні (до 600px) шапка й поля форми складаються в колонку, а кнопка розтягується на всю ширину. Так сторінка зручна і на комп'ютері, і на телефоні.

**2. Навіщо в полів name та id?**

name потрібен серверу: при відправці форми браузер передає пари name=значення, і Flask читатиме дані саме за name. id потрібен JavaScript для пошуку елемента на сторінці та для зв'язку з label (атрибут for), а також унікально ідентифікує елемент.
