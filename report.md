## Висновки та відповіді

**1. Що змінилося у виводі git status після git add?**

Після git add файли переходять до розділу Changes to be committed. Це означає, що вони додані до індексу та готові до commit.

**2. Що показує git diff?**

Команда git diff показує зміни у файлах: додані рядки позначаються знаком +, а видалені — знаком -.

**3. Чим відрізняється git switch main від git merge?**

git switch main перемикає на гілку main, а git merge об'єднує зміни іншої гілки з поточною.

**4. Чому виник конфлікт і як ти його розв'язав?**

Конфлікт виник через те, що в різних гілках було змінено один і той самий рядок файлу index.html. Я вручну об'єднав два варіанти заголовка, видалив службові маркери та завершив злиття commit-ом.
